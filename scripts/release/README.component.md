# A part of Holon

This distribution is one part of Holon, an LLM inference engine for one consumer NVIDIA GPU. Install `holonlm`,
which brings every part at one version, its prebuilt CUDA modules and the locks, and owns the `holon` command:

```bash
pip install holonlm
```

Source and documentation: <https://github.com/mxinO/holon>.
